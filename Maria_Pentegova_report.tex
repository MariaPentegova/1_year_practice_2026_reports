\section{Постановка задачи обхода в ширину на разреженных структурах}

Настоящая работа посвящена исследованию эффективности алгоритмов обхода в ширину (\foreignlanguage{english}{Breadth-First Search, BFS}) при обработке больших разреженных графов. Скорость выполнения этого алгоритма определяет общую производительность современных систем интеллектуального анализа данных, социальных сетей и поисковых движков. 

В рамках исследования рассматриваются два вычислительных варианта алгоритма: \texttt{parent-BFS} (с фиксацией дерева предков для каждой достижимой вершины) и \texttt{multisource BFS} (параллельный обход из фиксированного множества начальных источников). Реализация алгоритмов выполняется в двух базисах: классическом последовательном (на базе структур \texttt{CSR}~--- \foreignlanguage{english}{Compressed Sparse Row}) и линейно-алгебраическом (на базе открытого интерфейса \texttt{SuiteSparse:GraphBLAS}~\cite{graphblas-api}, преобразующего графовые операции в матрично-векторное умножение).


\textbf{Целью работы является} экспериментальное исследование влияния способов представления структур графа и использования интерфейса прикладного программирования \texttt{GraphBLAS} на время выполнения алгоритмов обхода в ширину.

\textbf{Актуальность и практическая польза} результатов заключаются в получении объективных эмпирических критериев выбора архитектуры программного обеспечения для обработки больших данных в зависимости от топологических свойств исследуемых сетей.

\textbf{Для достижения поставленной цели были сформулированы и решены следующие задачи}:
\begin{itemize}
    \item реализовать варианты \texttt{parent-BFS} и \texttt{multisource BFS} на языке C с использованием формата сжатого хранения строк (\foreignlanguage{english}{Compressed Sparse Row, CSR});
    \item разработать эквивалентные алгоритмы обхода средствами низкоуровневого интерфейса прикладного программирования библиотеки \texttt{SuiteSparse:GraphBLAS};
    \item спроектировать автоматизированный тестовый набор для проверки функциональной корректности разработанных программных модулей;
    \item измерить точное время выполнения алгоритмов на семи реальных грахах из репрезентативной коллекции разреженных матриц Университета Флориды (\foreignlanguage{english}{SuiteSparse Matrix Collection})~\cite{ssmc};
    \item выполнить детальный сравнительный анализ времени работы классического подхода на основе \texttt{CSR} и матрично-векторного подхода на основе \texttt{GraphBLAS}.
\end{itemize}


\section{Разработка низкоуровневых алгоритмов и подсистемы верификации инвариантов}

Программный комплекс реализован в виде независимых структурированных модулей на языке C (стандарт C11) без использования высокоуровневых абстракций. В данном разделе детально описывается низкоуровневое управление структурами данных, алгоритмы продвижения фронта обхода и логика разработанных автоматических тестов.

\subsection{Управление структурами данных и реализация последовательного обхода}

В рамках первого этапа работы в модуле \texttt{utils.c} были разработаны функции динамического управления структурами данных графа. Базовое чтение файлов формата Matrix Market (\texttt{.mtx}) реализовано вручную через функции потокового ввода \texttt{fgets} и \texttt{fscanf}. Поскольку граф является невзвешенным (\texttt{pattern}), ребра обрабатываются как логические связи. Парсер динамически строит граф в виде списков смежности, выделяя память под цепочки узлов \texttt{struct Node} через \texttt{malloc} и вставляя новые элементы в голову списка за $O(1)$. 

Для повышения локальности данных в памяти и ускорения обхода реализована функция \texttt{graph\_to\_csr}, преобразующая списки смежности в плоский формат сжатого хранения строк (\foreignlanguage{english}{Compressed Sparse Row, CSR}). Функция выполняет два последовательных прохода по графу:
\begin{itemize}
    \item \textbf{Первый проход:} вычисление степеней вершин и заполнение массива смещений \texttt{row\_ptr} накопительной суммой с выделением памяти под результирующий массив \texttt{col\_idx};
    \item \textbf{Второй проход:} линейное распределение идентификаторов соседей по ячейкам массива \texttt{col\_idx}. Для бесконфликтной записи используется временный массив счетчиков-смещений, инициализируемый нулями через функцию \texttt{calloc}.
\end{itemize}

Последовательный обход реализован в файле \texttt{classic\_bfs.c}. В качестве структуры данных для управления порядком обхода спроектирована линейная очередь \texttt{queue} на базе плоского динамического массива. Продвижение по очереди контролируется двумя индексами-указателями: \texttt{head} (индекс чтения элемента для обработки соседей) и \texttt{tail} (индекс записи вновь обнаруженных вершин). Добавление элементов в хвост и извлечение из головы выполняются с использованием постфиксного инкремента (\texttt{tail++} и \texttt{head++}). 

Массив \texttt{parent} инициализируется значениями $-1$ и выполняет двойную роль:
\begin{enumerate}
    \item Хранение идентификатора вершины-первооткрывателя (предка) для восстановления кратчайшего пути;
    \item Защитный маркер посещенных вершин (\foreignlanguage{english}{visited}), предотвращающий зацикливание алгоритма.
\end{enumerate}

В алгоритме \texttt{csr\_multisource\_bfs} (мультисоурсный обход) массив очереди \texttt{queue} на этапе подготовки принудительно заполняется идентификаторами всех четырех стартовых источников через цикл \texttt{for}, что моделирует параллельное (конкурентное) распространение независимых волн обхода из разных центров до момента их встречи на нейтральных вершинах.

\subsection{Интеграция с линейно-алгебраическим интерфейсом SuiteSparse:GraphBLAS}

Матрично-векторная версия алгоритма обхода реализована в модуле \texttt{graphblas\_bfs.c}. Для переноса топологии графа во внутреннюю структуру библиотеки SuiteSparse используется низкоуровневая функция импорта \texttt{GxB\_Matrix\_import\_CSR}. Импорт выполняется в безопасном режиме со значением флага \texttt{fast\_import = false}. Это заставляет библиотеку принудительно выполнить валидацию переданных массивов и автоматически отсортировать по возрастанию элементы \texttt{col\_idx} внутри каждой строки, компенсируя их изначальное убывающее расположение, вызванное ручной вставкой Си-узлов в голову списка.

Низкоуровневые операции управления очередью и пошаговый перебор смежных вершин в среде \texttt{GraphBLAS} заменены на строгие линейно-алгебраические абстракции над разреженными структурами:
\begin{itemize}
    \item \textbf{Вектор фронта (\texttt{frontier}):} разреженный логический вектор, заменяющий классический массив очереди. Активное состояние ячейки \texttt{true} детерминирует присутствие соответствующей вершины на текущей линии обхода графа;
    \item \textbf{Операция шага (\texttt{GrB\_vxm}):} векторно-матричное умножение вектора текущего фронта на булеву матрицу смежности графа $A$. Расчет производится на базе логического полукольца \texttt{g\_lor\_land\_semiring}, в котором мультипликативная операция заменена на логическое И (\texttt{GrB\_LAND}), а аддитивная~--- на логическое ИЛИ (\texttt{GrB\_LOR});
    \item \textbf{Управление историей посещений:} для отсечения уже пройденных вершин в функцию \texttt{GrB\_vxm} передается инвертированная маска вектора \texttt{visited}. Настройка этого поведения реализована через глобальный дескриптор \texttt{g\_desc\_visited\_comp\_replace}. Параметр аккумулятора функции умножения принудительно выставлен в \texttt{NULL}, что гарантирует получение абсолютно чистого изолированного слоя новых вершин на каждом шаге обхода. Запись вычисленных уровней в результирующий вектор выполняется массовым присвоением через \texttt{GrB\_assign}.
\end{itemize}

\subsection{Изоляция измеряемых факторов алгоритма}

Для обеспечения методологической чистоты эксперимента все исследуемые алгоритмы обхода были разработаны самостоятельно непосредственно поверх базового ядра библиотеки \texttt{SuiteSparse:GraphBLAS}. Использование готовых высокоуровневых реализаций обхода из сторонних проектов, таких как \texttt{LAGraph} или \texttt{Boost Graph Library}~\cite{lagraph,boost-graph}, было намеренно исключено на этапе проектирования экспериментального стенда. 

Развитые графовые библиотеки содержат внутренние динамические эвристики, такие как направление-оптимизированный поиск (\foreignlanguage{english}{direction-optimizing BFS}), автоматическое переключение форматов векторов фронта (между разреженным и плотным представлениями) и специфичные скрытые механизмы предвыборки памяти. Включение таких сторонних абстракций в контур тестирования привело бы к смешению измеряемых факторов, делая невозможным корректное сопоставление базовой эффективности самой матрично-векторной концепции \texttt{GraphBLAS} с последовательным обходом структуры \texttt{CSR}. 

Самостоятельная реализация алгоритма гарантирует строго эквивалентные стартовые условия запуска: единый распределитель памяти, послойное (классическое «ориентированное вперед») продвижение фронта волны и идентичные критерии останова по пустому вектору для всех рассматриваемых вариантов. Это позволяет изолировать программные эвристики и оценить чистый вклад линейно-алгебраической модели вычислений в общую производительность анализа сетей.



\subsection{Архитектура автоматизированного тестирования}

Для обеспечения стопроцентной надежности программного кода разработана независимая подсистема тестов (каталог \texttt{src/tests}), управляемая встроенным в CMake механизмом \texttt{enable\_testing()}. В файле \texttt{test\_utils.c} реализованы функции генерации жестко зашитого в памяти эталонного графа из 5 вершин и матрицы расстояний \texttt{expected[5][5]}.

Валидация кодовой базы опирается на системные макросы \texttt{assert(...)} и разделена на три изолированных этапа проверки инвариантов:
\begin{enumerate}
    \item \textbf{Проверка связности дерева предков (\texttt{test\_classic\_bfs.c}):} автоматически проверяется, что стартовый корень строго указывает сам на себя, все достижимые вершины избавлены от значения $-1$, а у промежуточных вершин отсутствуют изолированные циклические петли на самих себя;
    \item \textbf{Перекрестное побитовое сравнение (\texttt{test\_comparison.c}):} результаты выполнения последовательного обхода на очередях из \texttt{classic\_bfs.c} поэлементно сравниваются с результатами работы векторных функций GraphBLAS. Любое расхождение в вычисленных уровнях или предках приводит к мгновенной аварийной остановке теста;
    \item \textbf{Тестирование мультисоурсного инварианта (\texttt{test\_graphblas\_bfs.c}):} проверяется математический закон графов, согласно которому расстояния до вершин при множественном старте обязаны быть строго меньше или равны расстояниям при одиночном старте (\texttt{level[i] <= level\_single[i]}).
\end{enumerate}


\section{Экспериментальное исследование и сравнительный анализ производительности}

Экспериментальное исследование направлено на измерение точного времени выполнения алгоритмов. В данном разделе приведены технические параметры вычислительного стенда, метрики входных графов и результаты сравнительного анализа временных показателей.

\subsection{Спецификация стенда и характеристики тестовых графов}

В качестве измеряемой метрики принято среднее арифметическое времени работы в микросекундах. Все эксперименты проводились на изолированном вычислительном стенде со следующими фиксированными параметрами окружения:
\begin{itemize}
    \item центральный процессор Intel Core Ultra 7 255H;
    \item объем доступной оперативной памяти составляет 32 ГБ;
    \item операционная система Ubuntu 26.04.1 с длительным периодом поддержки (\foreignlanguage{english}{Long Term Support, LTS});
    \item набор компиляторов \texttt{GCC} (\foreignlanguage{english}{GNU Compiler Collection}) версии 15.2.0;
    \item библиотека SuiteSparse:GraphBLAS версии 7.4.0;
    \item параметры оптимизации компилятора: \texttt{-O3 -DNDEBUG} (стандарт C11).
\end{itemize}

В качестве входных данных использовались семь разреженных матриц из коллекции \texttt{SuiteSparse Matrix Collection}~\cite{ssmc}. Загрузка осуществлялась из файлов матричного формата Matrix Market. Анализ экспериментальных данных указывает на сильную зависимость эффективности исследуемых подходов от типа направленности ребер (ориентированные и неориентированные топологии), а также от общей структуры связности входных графов:
\begin{itemize}
    \item Реализации на основе \texttt{GraphBLAS} (\texttt{GB-L} и \texttt{GB-M}) продемонстрировали существенное преимущество на крупномасштабных неориентированных графах социальных сетей (\texttt{com-Orkut} и \texttt{soc-LiveJournal1}). На симметричной матрице \texttt{com-Orkut} среднее время выполнения сократилось примерно в 3.91 раза, на \texttt{soc-LiveJournal1}~--- в 3.67 раза. Высокая эффективность линейно-алгебраического подхода на данных неориентированных топологиях обусловлена степенным распределением степеней вершин (наличием «хабов») и малым топологическим диаметром сети. Взаимная связность ребер приводит к тому, что размер вектора фронта (\texttt{frontier}) возрастает лавинообразно, позволяя параллельным векторным механизмам SuiteSparse максимально эффективно использовать вычислительные ресурсы процессора при матрично-векторном умножении;
    \item Классический \texttt{CSR}-подход (\texttt{CP} и \texttt{CM}) оказался значительно эффективнее как на неориентированных дорожных сетях (\texttt{roadNet-CA}, \texttt{road\_usa}), так и на сильно разреженных ориентированных графах цитирований и веб-ссылок (\texttt{cit-Patents}, \texttt{web-Google}). На ориентированном графе веб-страниц \texttt{web-Google} классический BFS на очередях опередил GraphBLAS в 8.09 раза, а на дорожной сети \texttt{road\_usa} в режиме мультипоиска последовательный обход превзошел матрично-векторный аналог в 73.71 раза. Указанные структуры (как направленные, так и ненаправленные) характеризуются низким средним числом связей у вершин и большим топологическим диаметром. При послойном обходе таких сетей размер текущего фронта на каждой итерации остается крайне малым, из-за чего накладные расходы библиотеки на диспетчеризацию вызовов и внутреннее управление масками в функции \texttt{GrB\_vxm} многократно превышают время полезных вычислений.
\end{itemize}

Зафиксированные показатели принимаются как верифицированный эмпирический базис исследования. Поуровневый замер динамического изменения размера фронтов в рамках текущей работы не производился.

\section{Заключение}

В ходе выполнения настоящей работы были успешно решены все поставленные задачи и получены следующие основные результаты:
\begin{itemize}
    \item на языке C (стандарт C11) реализованы четыре варианта алгоритма обхода в ширину, базирующиеся как на классическом последовательном подходе с использованием низкоуровневых структур данных \texttt{CSR}, так и на линейно-алгебраическом подходе на основе библиотеки \texttt{SuiteSparse:GraphBLAS};
    \item спроектирована модульная инфраструктура автоматизированного тестирования, обеспечивающая перекрёстную валидацию результатов и проверку топологических инвариантов дерева предков, что гарантирует полную логическую корректность разработанного программного обеспечения (\texttt{100\% passed});
    \item проведены детальные экспериментальные замеры времени выполнения обхода на семи реальных крупномасштабных графах различной направленности (ориентированные графы веб-ссылок и цитирований, неориентированные социальные и дорожные сети) из коллекции \texttt{SuiteSparse Matrix Collection};
    \item на основе полученных эмпирических данных выявлены и обоснованы границы применимости исследуемых подходов. Доказано, что применение \texttt{GraphBLAS} обеспечивает ускорение вычислений до 3.91 раза на неориентированных социальных сетях с малым диаметром и высокой степенью кластеризации вершин за счёт эффективных внутренних векторных оптимизаций SuiteSparse на крупных фронтах. Напротив, для дорожных сетей и сильно разреженных ориентированных иерархических структур последовательный обход на структурах \texttt{CSR} демонстрирует безусловное преимущество (до 73.71 раза), поскольку накладные расходы библиотеки на разреженных фронтах малой размерности превышают время полезной работы.
\end{itemize}
